# Process symbol reference

Render `ProcessSymbolsDemo` in a Foundry starter with its existing theme and stylesheet. It shows each execution state, selected and unselected ready steps, and independent optionality using the actual `ProcessSteps` component. These are individual examples, not one workflow.

The source imports framework code for pre-release review. Downstream apps use the published package after release. See `docs/PROCESS_GUIDE.md` for host navigation, prerequisites, optional skips and localization.
